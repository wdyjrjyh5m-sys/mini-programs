## 目录规范

每个小程序一个独立子目录：

```
<project-name>/
├── README.md    # 功能说明、运行方式
├── miniprogram/ # 小程序源码
└── docs/        # 设计与部署文档
```

## 发布前检查清单

上传前务必确认：

1. 无硬编码的 AppID、AppSecret、API Key 等凭据。
2. 无测试账号、真实手机号、客户数据。
3. 敏感配置用环境变量或 `.env.example` 占位，真实值不入库。
